# Escape Into Studio — Downloads

This repository is for **public installer downloads only**. The application source code is maintained privately.

## Installers

When a tested release is published, the files will appear on the [Releases page](https://github.com/timmerriman-droid/escape-into-downloads/releases):

- **Mac (Apple Silicon)** — for newer Macs with Apple chips.
- **Mac (Intel)** — intended for older Intel Macs. Catalina compatibility needs testing.
- **Windows (x64)** — installer for 64-bit Windows.

**Status:** No installers have been publicly released yet. Initial builds are untested and should not be treated as ready-to-use downloads.

## Safety

This repository contains no application source code, passwords, or API credentials. Test installers may trigger macOS Gatekeeper or Windows SmartScreen warnings until signed and verified.
